# INDIE-CORPUS-01 — Does the ledger edge survive an author who isn't us?

**Question.** Every natural-language validation in this program
(LOCAL-EXTRACTION-01, FREETEXT-01) used sentences written by the
system's own author. FREETEXT-01's report named this its standing
caveat: the corpus and the system share a mind, so the measured
edge might partly be authorial self-agreement. This run breaks it:
the corpus was authored end-to-end by a *different model family*.

**Instrument.** `prototype/validation/indie_corpus.py` (committed
before the run): 144 sentences — 6 true + 6 false renderings of
each of the 12 newsroom facts — generated by **OpenAI GPT-4.1**
(`indie_generate.py`, 12 calls, one per fact) under a prompt that
demanded unambiguous assertion and wide stylistic variety (wire
copy, blogs, official statements, headlines, quoted speech, social
posts). Ground truth by construction (the generator was told which
cell each sentence belonged to). Screening, all disclosed:
mechanical rejects at generation (anchor/dedup/leakage rules)
**0**; the system author's blatant-mislabel read-through rejects
**0 of 144** — no sentence was edited, only the generation prompt
and fact list are ours. The extractor under test is the same local
Qwen3-8B (`LocalExtractor`, llama.cpp on the owner's desktop) as
LOCAL-EXTRACTION-01 and FREETEXT-01; Part 1 is the pooled census,
Part 2 rebinds `newsroom.FACTS` to the indie pools (5 seeds × 60
steps, 4,800 quizzes), identical protocol throughout.

**Run incident, recorded:** mid-Part-2 (during seed 3) both the
runner and llama-server died silently on the desktop — no
traceback, WSL uptime uninterrupted; cause unknown, plausibly
external to the run. The checkpointed runner was relaunched
against a restarted server and resumed at seed 3; no data was
re-measured or lost.

## Part 1 — extraction census

**140/144 = 0.972.** The identical headline to FREETEXT-01's
0.972 — and an entirely different failure anatomy (1 fact error,
3 value errors, 0 raises):

- **The only fact error is a keyword collision:** *"AstraCorp's
  CEO, John Rodriguez, was instrumental in this year's merger,"*
  → mapped to fact 11 (the Northwind–Skylink *merger*), value
  False. The word "merger" outvoted the sentence's actual subject.
- **All three value errors are the same device the home-authored
  corpus never used: direct quoted speech asserting the fact.**
  *"‘We did it! Team Falcons won the championship!’ exclaimed head
  coach Maria Lopez…"* → False. *"‘As part of our growth strategy,
  QuantumLeap has enacted a 2-for-1 stock split,’ CEO Linda Choi
  said…"* → False. *"‘We are delighted to announce that the Kestrel
  pipeline is operational,’ said CEO Dana Miller…"* → False.
  Quoted *denials* in the corpus were extracted correctly, so the
  pattern is asymmetric: affirmation inside quotation marks flips
  to False (n=3; a pattern, not yet a mechanism).
- FREETEXT's signature failure — present-state phrasings of
  Vantia's parliament being undissolved — does **not** recur:
  GPT-4.1's false pool for fact 7 uses similar phrasings
  ("remains intact and continues to operate", "still in session"),
  and all were extracted correctly. Different author, different
  weaknesses probed. That is the point of the exercise.

## Part 2 — newsroom, independent prose

| | ledger err | naive err | | ledger derived | naive derived |
|---|---|---|---|---|---|
| **INDIE-CORPUS-01** | **0.1358** | **0.1721** | | **0.1467** | **0.2917** |
| FREETEXT-01 | 0.1371 | 0.1648 | | 0.1442 | 0.2550 |
| Templates (LOCAL-EXTRACTION-01) | 0.1506 | 0.1935 | | 0.1108 | 0.2825 |

- **Error eliminated vs naive: 21.1% overall, 49.7% derived** —
  between FREETEXT (16.8% / 43.5%) and templates (22.2% / 60.8%),
  on prose no one in this program wrote.
- **Seed record 4/5** (FREETEXT 3/5, templates 5/5): wins on
  seeds 0, 1 (by 0.001), 2, 4; a clear loss on seed 3
  (0.166/0.136, derived 0.183/0.067 — the loss is real and is not
  argued away).
- Seed 4 again produced a naive derived collapse to **0.600**
  (identical to FREETEXT's seed 4) against ledger derived 0.096 —
  the same hostile stream shape breaking the naive agent the same
  way under a third prose source.
- **Sensitivity, stated both ways as before:** excluding seed 4,
  the edge is **8.6% overall / 25.8% derived**. FREETEXT's
  equivalent figures were 3.0% / 10.5% — the independent corpus's
  edge is *less* dependent on the catastrophic seed than the
  home-authored one's was.

## Verdict

The authorship caveat is retired. On prose authored by a different
model family — with a different stylistic repertoire (quoted
speech, alternative-CEO inventions, social posts) and a different
failure profile — the ledger's advantage reproduces at the same
order: roughly a fifth of naive error eliminated overall, half on
derived claims, with the advantage concentrated, as always, in
the seeds where naive reasoning fails coherently. The extractor
weaknesses this corpus exposed (quoted affirmations flipping, one
keyword collision) are extraction-layer findings; they enter the
ledger as ordinary evidence noise, which is precisely the
condition the ledger exists to absorb.
